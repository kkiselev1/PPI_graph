# PPI_graph

Белок-белковые взаимодействия для человеческого белка TP53 по двум базам данных: STRING и BioGRID.

## Данные

Для STRING использовались данные по физическим взаимодействиям человека и файл с информацией о белках.

Для BioGRID была использована выгрузка взаимодействий для TP53.

В анализе рассматривались физические взаимодействия человека.

## Сравнение покрытия STRING и BioGRID

После построения графов были получены следующие результаты:

- BioGRID: 2203 белка
- STRING: 2056 белков
- Общие белки: 1596
- Только BioGRID: 607
- Только STRING: 460

Перекрытие составило:

- 72.45% относительно BioGRID
- 77.63% относительно STRING

Две базы достаточно сильно пересекаются, но не содержат полностью одинаковый набор взаимодействий.

## Типы доказательств

BioGRID хранит информацию о конкретных экспериментальных методах, которыми было подтверждено взаимодействие.

Наиболее часто встречались:

- Affinity Capture-Western
- Affinity Capture-MS
- Reconstituted Complex
- Proximity Label-MS
- Biochemical Activity
- Two-hybrid
- Co-localization

STRING использует несколько каналов доказательств для одной связи.

В полученной выборке:

- experimental: 3518 взаимодействий
- database: 144 взаимодействия
- textmining: 1430 взаимодействий

BioGRID в большей степени ориентирован на конкретные экспериментальные методы, а STRING объединяет несколько источников информации и присваивает взаимодействию итоговый score.
